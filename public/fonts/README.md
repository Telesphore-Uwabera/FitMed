# Kind Sans Font Files

Place your **Kind Sans** font files in this folder (`public/fonts/`).

Supported file formats & standard filenames:
- `KindSans-Regular.woff2` (or `.woff` / `.otf` / `.ttf`) — Weight: 400
- `KindSans-Medium.woff2` (or `.woff` / `.otf` / `.ttf`) — Weight: 500
- `KindSans-SemiBold.woff2` (or `.woff` / `.otf` / `.ttf`) — Weight: 600
- `KindSans-Bold.woff2` (or `.woff` / `.otf` / `.ttf`) — Weight: 700

The `@font-face` rules in `src/app/globals.css` are configured to automatically load these font files as soon as they are added here.
